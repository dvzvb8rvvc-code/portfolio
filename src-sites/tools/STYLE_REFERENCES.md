# Style references — one per site (batch 5)

Each site in this batch is assigned ONE reference below. Translate that brand's design DNA to a local Minsk business — don't copy their logos, text, products or assets. Read BRIEF_MINSK_PRO.md too (all its rules still apply). Inspiration galleries to think in: awwwards.com (Sites of the Day), godly.website, land-book.com, lapa.ninja, siteinspire.com.

## A. Apple product page (iPhone / AirPods / MacBook)
- White or near-black canvas, SF-like grotesk (Inter Tight / Manrope), huge centred headlines, short one-line sublines.
- Signature: the product is the hero — a 3D object pinned while scroll rotates / explodes / re-assembles it; captions fade in one at a time centred under it. "Highlights" carousel of rounded cards. Spec "tech specs" table at the end.
- Motion: slow, eased, scrubbed. Lots of whitespace. Accent colour used once per section.

## B. Stripe
- Animated mesh-gradient WebGL background (flowing soft colour fields, slanted section edges -6deg).
- Crisp typography (Inter / "Sohne"-like), dense but very clean grids, small code-like UI cards floating with soft shadows, thin 1px borders.
- Signature: skewed gradient band behind hero; interactive "product UI" mock (a booking widget/dashboard) that animates states.

## C. Linear
- Dark (#08090a), subtle radial glows, 1px borders with gradient highlight that follows cursor, glassy cards.
- Typography: Inter Display, tight, gradient white-to-grey text. Keyboard-shortcut chips, command menu (⌘K-style booking palette).
- Signature: hero with a perspective-tilted app screenshot (here: stylised UI of the business's booking/plan), light beam lines, grid of features with glowing border on hover.

## D. Vercel
- Strict black & white, Geist-like font (use "Geist" from Google Fonts if available, else Inter), mono labels, perfect 8px spacing, dotted/cross grid background.
- Signature: centred triangle/prism geometric hero with light rays; sections separated by thin rules; numbers in mono; everything aligned to a visible grid.

## E. Nothing (nothing.tech)
- Monochrome + one red accent, dot-matrix typography (use "DotGothic16" or "Doto" for display + clean grotesk for body), glyph-like LED patterns.
- Signature: transparent "see-through" 3D object showing internals, dot-matrix animated counters/icons, playful but technical microcopy.

## F. Tesla
- Full-screen sections, each one huge visual + 1 line + 2 buttons ("Записаться" / "Подробнее"), scroll-snap between slides.
- Minimal text, centred title at top of each slide, buttons at bottom. Visuals are 3D scenes rendered full-bleed (studio lighting), no clutter.

## G. Rivian
- Cinematic, outdoorsy premium: earthy palette (forest, sand, sky), big editorial serif or wide grotesk, film-like letterbox, slow camera moves through a 3D landscape.
- Signature: scroll-driven "journey" with chapter titles, cards that feel like field notes, warm light.

## H. Bang & Olufsen
- Luxury and air: warm neutrals (oak, aluminium, cream), elegant thin serif + light sans, enormous margins, few elements per screen.
- Signature: a single precious object in 3D (anodised aluminium / oak / fabric materials) slowly turning, material swatches selector, quiet hover states.

## I. Teenage Engineering
- Toy-like industrial design: off-white/grey, small bold mono/grotesk, orange + blue accents, tiny pixel icons, product-manual aesthetic.
- Signature: interactive "device" UI (knobs, buttons, toggles that click with physical feel), exploded diagrams with numbered callouts, compact grid of product tiles.

## J. Arc browser (arc.net)
- Playful, colourful pastel gradients, rounded "sticker" shapes, bouncy springs, hand-drawn underlines, friendly copy.
- Signature: a living UI demo that rearranges itself (cards spaces/tabs fly around), confetti-light delight moments, cursor-reactive blobs.

## K. Raycast
- Dark, glassmorphism (frosted panels with blur & inner glow), 3D glossy icons/keys, neon red-to-pink accents, keyboard theme.
- Signature: command-bar booking ("Найти услугу…" with live filtering and ↵ to choose), 3D keycaps in hero, extensions-like grid.

## Rules for using a reference
- Use the reference's layout logic, motion language, typography attitude and colour discipline — NOT its literal content.
- Combine with the business's own story and a value interaction (from BRIEF_MINSK_PRO.md).
- No two sites in this batch may look alike even when niches repeat.
